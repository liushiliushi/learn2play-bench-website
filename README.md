# Learn2Play Bench — project website

Static research homepage, published with GitHub Pages.

## Preview

Run `python3 -m http.server 8791` in this directory, then open http://localhost:8791.
No package installation or build step is needed.

## Update

- `index.html`: research overview, external links, and evaluation description.
- `app.js`: result snapshot and game descriptions.
- `styles.css`: responsive visual design.
- `research.css`: research-first layout, added September 29, 2026.
- `assets/learning-{backbones,methods,humans}.svg` and `assets/learning-curves.json`: website-sized figures exported by the parent project's `tools/export_website_curves.py`. They use the manuscript's unchanged `paper_metrics.challenge_weighted_curve` function and canonical data with an in-memory Opus 5.5 cohort, not values estimated from an image. The existing canonical results are unchanged; the new cohort uses the same normalization and weights. Progress is interpolated across each game's retained reporting window, not ten scored episodes for every game. No error bands are implied.

The gameplay explorer covers all 20 templates. `assets/game-examples.json` is generated by the parent project's `tools/export_website_game_examples.py` exclusively through `play.py`, validating every example command against the current valid actions. `--no-finalize` is used for these incomplete UI previews only, never for scored evaluations. These are recorded action/observation sequences, not live play, model results, or recommended strategies. RedEye explicitly shows its unscored prologue. No hidden source rules, private model logs, or credentials are included. Curve-data download links were removed at the user's request; existing curve assets remain for provenance.
- `cost-chart.js` renders the white-background interactive performance–cost chart and its static SVG fallback. `assets/performance-cost.json` preserves all 29 existing coordinates from `results/_analysis/rq6_cost_audit.csv` and adds OpenCode + Claude Opus 5.5 from its verified cohort performance and cost analyses, with hashes for each source; `scripts/export-cost-data.py` exports these without recomputing metrics. Performance is normalized Max; cost is estimated mean USD per episode, using the manuscript's August 30, 2026 pricing snapshot and cache assumptions for the original models. Opus 5.5 uses Anthropic standard prices accessed October 7, 2026 ($4 input, $20 generated, $0.20 cache read, and $5 five-minute cache write per million tokens). Its 4,553 unique step reports cover 60 retained trials and 600 collected episodes, including both segments of resumed runs; superseded attempts are excluded. Its mean estimated cost is $1.0608687907 per episode. These are public-rate estimates, not gateway charges. The website uses a standard logarithmic cost axis, explicitly labeled, and a linear 20–90% score axis. The frontier refers to the 30 configurations with known costs, including when filters are active. Hover, click, or keyboard focus shows full configuration names and values. Rebuild the static fallback with `node scripts/export-cost-svg.cjs` after editing the renderer or data. The previous PNG remains an archived asset. These estimates are not billing records or current price quotes.

The leaderboard uses the manuscript's main backbone/method and harness comparison tables (October 8, 2026). The default panel contains 11 OpenCode models, including Opus 5.5 (Max 80.1, Mean 61.0, LG +23.0, LS +5.22), plus Human Top-1, Top-3, Top-5, and Human Mean references from the manuscript. Top-k selects players independently per game by their observed peak; Human Mean covers all eligible participants. All use the same 20 games and challenge weights. Human comparisons describe this study sample, not population-level ability. No completed Claude Code + Opus 5.5 or Opus 5.5 self-evolving-method results are included; those comparisons are unchanged. Default ranking is Max, descending; users can choose Mean, Learning Gain (LG), or Learning Slope (LS). Ties share competition ranks (1, 1, 3) at displayed precision. These are point estimates, not statistical-significance ranks or automatically updated results. Methods and harnesses are ranked only within the selected backbone. Preserve comparison groups when updating. The matched-transfer discussion is qualitative and does not claim every model declines.

The game portal is hosted separately and requires sign-in. This repository contains no game server, credentials, private logs, or unfinished manuscript PDF. A benchmark-code button is intentionally omitted: the manuscript's anonymous archive returned HTTP 401 (`not_connected`) during deployment verification. Add a code link once a publicly accessible release is confirmed; do not expose a private repository.

Publishing source: `main`, root directory. Commit and push changes to update the website.
