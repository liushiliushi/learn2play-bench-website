EXPERIENCE

Keep the evidence.

With Kimi K3, full interaction histories achieve the best or tied-best result on all four metrics among the six compared methods. Summarizing experience is not always better.

AGENT HARNESS

The framework matters, too.

With Opus 5 fixed, Claude Code reaches a Max of 81.8, compared with 74.5 for OpenCode. The surrounding software affects how a model learns and acts.

TRANSFER

New situations test old lessons.

In the same-game comparison, re-shuffling reduces learning slope for many configurations, but not all. Learning a useful rule and reusing it are distinct challenges.

02 / THE BENCHMARK

Solving a task isn't the same
as learning from it.

A high score tells us what an agent can do. Repeated interaction helps us examine what it learns.

01

Discover, don't look up.

Novel, sometimes counterintuitive rules create unfamiliar situations. Agents see actions and feedback—not game source code or solutions.

02

Experience should matter.

Agents play multiple episodes. Different methods retain past experience as full histories, reflections, rules, or workflows.

03

Test what carries over.

Fixed games repeat an instance. Re-shuffled games change its surface details while keeping the underlying rules the same.

EVALUATION AT A GLANCE

One game. Repeated attempts.
A measurable learning trajectory.

The main evaluation uses 5 episodes for normal games and 10 for challenge games, with a protocol of 3 independent trials. Scores are normalized per game. Challenge games receive weight 3 and normal games weight 1 in aggregate results.
